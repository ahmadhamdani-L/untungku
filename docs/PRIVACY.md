# Draf kebijakan privasi UntungKu Pro

Status: draf berdasarkan build pengembangan; pemilik harus mengisi kontak dan meninjau sebelum publikasi.

UntungKu Pro menyimpan produk, penjualan, pengeluaran, stok, nama usaha, dan preferensi secara lokal di perangkat. Build pengembangan tidak memiliki akun wajib, server bisnis, analitik, atau permintaan iklan aktif. Izin internet disertakan untuk dukungan SDK iklan yang belum diaktifkan.

Pengguna memilih lokasi penyimpanan backup JSON dan ekspor CSV melalui pemilih berkas Android. Berkas dapat memuat informasi usaha. Pengguna bertanggung jawab menyimpan dan membagikannya dengan aman. Pemulihan backup mengganti data setelah konfirmasi dan membuat salinan pemulihan internal.

Menghapus aplikasi menghapus database dan salinan pemulihan internal. Backup Android otomatis dinonaktifkan pada manifest; lakukan backup manual ke lokasi eksternal. Penghapusan transaksi penjualan dilakukan melalui pembatalan agar riwayat stok konsisten; pengeluaran dapat dihapus. Arsip produk mempertahankan histori.

SDK Google Mobile Ads merupakan dependensi aplikasi, tetapi tidak diinisialisasi pada build default. Jika iklan diaktifkan kelak, kebijakan ini dan deklarasi Data safety wajib diperbarui berdasarkan perilaku SDK, persetujuan pengguna, wilayah, dan data yang benar-benar diproses.
