# Draf kebijakan privasi UntungKu Pro

Status: draf untuk profil offline dan owner beriklan; pemilik harus mengisi kontak dan meninjau sebelum publikasi.

UntungKu Pro menyimpan produk, penjualan, pengeluaran, stok, nama usaha, dan preferensi secara lokal di perangkat. Build pengembangan tidak memiliki akun wajib, server bisnis, analitik, atau permintaan iklan aktif. Izin internet disertakan untuk dukungan SDK iklan pada profil owner.

Pengguna memilih lokasi penyimpanan backup JSON dan ekspor CSV melalui pemilih berkas Android. Berkas dapat memuat informasi usaha. Pengguna bertanggung jawab menyimpan dan membagikannya dengan aman. Pemulihan backup mengganti data setelah konfirmasi dan membuat salinan pemulihan internal.

Menghapus aplikasi menghapus database dan salinan pemulihan internal. Backup Android otomatis dinonaktifkan pada manifest; lakukan backup manual ke lokasi eksternal. Penghapusan transaksi penjualan dilakukan melalui pembatalan agar riwayat stok konsisten; pengeluaran dapat dihapus. Arsip produk mempertahankan histori.

SDK Google Mobile Ads merupakan dependensi aplikasi, tetapi tidak diinisialisasi pada build default. Profil owner mengaktifkan banner Google AdMob setelah UMP mengizinkan permintaan. Google dapat memproses informasi perangkat/aplikasi, alamat IP, interaksi iklan, serta diagnostik sesuai konfigurasi SDK dan persetujuan. Data transaksi tidak dikirim aplikasi ke server bisnis. Pengguna dapat mengubah pilihan privasi melalui pengaturan jika diwajibkan UMP. Pemilik wajib memverifikasi deklarasi Data safety berdasarkan perilaku SDK aktual, wilayah, dan pengaturan akun. Lihat https://policies.google.com/privacy dan https://developers.google.com/admob/flutter/privacy.
