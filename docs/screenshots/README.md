# Bukti UI pengujian

Capture layar aplikasi Android saat pengujian manual, mencakup onboarding, layar kosong, kalkulator, tema, pengaturan dan konfirmasi restore. Ukuran mengikuti konfigurasi emulator saat capture; untuk bahan listing gunakan `../store-screenshots` yang berukuran seragam. Tampilan konfirmasi restore diambil ketika pengujian backup melalui pemilih berkas Android.
